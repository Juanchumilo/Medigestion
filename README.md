# Medigestion

Medigestion es un Proyecto personal del tecnologo Analisis y Desarrollo de Software del SENA Colombia. 
El proyecto consiste en una app web que tenga como funcion la gestion de citas medicas. 

## Dependencias
Medigestion esta hecho con 3 lenguajes: HTML,CSS y python-flask.
Las dependencias que deben ser descargadas son:

-- Python
-- Flask
-- bcrypt
-- datetime

Todas estas dependencias deben ser instaladas en un entorno virtual preferiblemente, como sugerencia personal recomiendo venv, ya que viene instalado con python.

## 🚀 Instalación

```bash
git clone https://github.com/Juanchumilo/Medigestion.git
cd Medigestion
```

Despues de clonar el repo, se debe si o si eliminar las carpetas:

-- .vscode
-- __ pycache __  #Esta esta dentro de la carpeta /app/


Si no se eliminan podria generar problemas
